# 三视图解读与防呆指南

## 读图顺序
1. **判断投影法**：国内国标第一角投影——主视图在左上，俯视图在主视图正下方，左视图在主视图正右方。
   若布局不同（俯视在上、左视在左）则为第三角投影，按镜像对应调整。
2. **对齐校验**：主/俯视图长对正；主/左视图高平齐；俯/左视图宽相等。三视图之间尺寸必须自洽。
3. **提取尺寸**：识别全部标注（直径 ⌀、半径 R、倒角 C、角度、板厚、孔距）。中心线/点画线定位孔与对称面。

## 特征识别
- 粗实线 = 可见轮廓；细虚线 = 隐藏的孔/槽/内腔；点画线 = 中心线/孔轴线。
- 圆 + 中心线 → 孔；同心圆 → 台阶孔/沉孔；虚线矩形 → 通槽/通孔；R 标注 → 圆角。
- 多个视图中对应轮廓合并成一个特征：如主视图矩形+俯视图孔位 → 底板 pad + 若干 hole。

## 基准与原点对齐（硬要求）
- 把**主要对称面或加工基准面**与绝对平面对齐：底板在 XY 平面上建模（Z 向为厚度）。
- 原点选择：基准孔中心、或底板几何中心/角点。在 `datum` 中写明选择理由。
- 立板/耳板的草图平面按需选 XY/YZ/ZX，使拉伸方向与图纸厚度方向一致。

## 防呆规则（硬要求，违反即返工）
出现以下任一情况，**立即停止建模，先向用户提问**，严禁编造或臆测尺寸：
1. 关键尺寸缺失（如总长/总宽/总厚未标、孔距未标、孔径未标）。
2. 三视图投影关系矛盾（长/宽/高在三个视图对不上）。
3. 虚线/隐藏结构无法唯一确定（内部空腔、台阶孔级数不明）。
4. 视图不完整（缺一个基本视图、剖面缺失）。
5. 比例/单位不明（未注单位、标题栏比例无法换算）。

提问要**一次问完**，给出候选值而非开放式问题，例如：
> "俯视图中两个孔的中心距未标注；若按底板总长 100mm 居中布置，孔中心距为 80mm，是否按此建模？"

## 多零件拆分
- 图纸为单一零件 → 一个 part，挂到产品树下。
- 图纸含多个独立零件/装配 → 拆成多个 `.CATPart`，按装配关系给每个零件 `position` 平移定位。

## 输出检查
建模后必须：
1. 脚本 `--capture` 输出 JPG 预览；
2. 用 Read 打开预览图，与三视图逐一核对（轮廓、孔位、圆角、厚度）；
3. 不一致则修正特征 JSON 重新生成，**不得**交付未核对的模型。
